# _drafts

Folders that start with an underscore are not published by GitHub Pages (Jekyll skips them), so anything here is not reachable at www.513sips.com.

`_drafts/blog/` holds four blog posts that were live before Eddie reviewed them. They are kept for review. When a post is approved, move it back to `blog/`, link it from `blog/index.html` and add it to `sitemap.xml`.

Do not add a `.nojekyll` file to this repo: it would publish everything in this folder.
